# 序

月光被树冠的獠牙撕碎，在烟雨垂落的黑发上碎成细小的光斑。她单手拎起羊皮卷轴一抖：
「看穿幻象的宝石，总比你那根烧焦的火蜥蜴尾巴值钱？」

一旁的狼兽人骸云正蜷着后腿蹲坐在树根处，尾巴有一搭没一搭地拍打地面。他弓着脊背调试弓弦的姿态，总让人想到铁匠铺里歪斜的招牌。
「至少够补偿旅店老板的屋顶窟窿洞吧...？」

少女突然气愤地把卷轴怼到狼人鼻尖，陈年的鞣制气味直冲鼻腔。骸云的左耳应激般后折成投降角度，一个响亮的喷嚏炸开。
「那是谁非要叼着活火蜥蜴，在房梁上蹦跶来着？」

委屈的呜咽声从喉咙深处滚出，看样子狼是拒绝回答这个问题。

烟雨盯着他那副油盐不进的蠢样，鼻腔里逸出一声冷哼。她抽回卷轴，仔细端详起羊皮表面，眉头微蹙。

「……这山形——」
她指尖划过羊皮上的墨迹，「按这个轮廓，瘴气应该在这，西南角？……可我们现在的位置……不对。」

「这可是用三张上等雪貂皮换的，」骸云喉间咕哝，声音闷得像含了口泥浆。
「瘴气在东北角——」他鼻翼忽然翕动，猛地抬头，

「大小姐，你地图拿倒了！」

少女瞪了狼一眼，随后“啪”地把地图卷了回去。

# 雾径

月光被树冠的獠牙撕碎，铺在通往雾深处的腐叶小径上。

「祭坛就在里面。」烟雨的声音割开沉寂，一丝不易察觉的紧绷藏在尾音里。「卷轴说，看透虚妄的宝石就在森林心脏的祭台上。」

「听起来能换座小金山。」骸云尾尖稍稍抬高，扫开脚边的湿气。
「白天伪装成温顺的小羊，夜晚正适合露出獠牙！」他爪尖拨弄着箭袋里的羽翎，「大小姐，第一次正经探险吧？这比工会那些挠痒痒的差事带劲多了！」

「哼，工会那些玩意儿，连热身都不算。」烟雨下颌微扬，眼神冷厉。

越往深处，景色越发朦胧。月光逐渐被雾气吞没，只能勉强照亮脚下崎岖的小路，四周寂静得只剩下他们的脚步声和树叶的沙沙声。

穿过一片灌木丛生的地带，对于经验丰富的冒险者来说，这里的每一个阴影都可能隐藏着危险。
正如二人所料，一只史莱姆悄无声息地从灌木丛中现身

少女只需与狼一个对视， 无需多言。

骸云利爪破风，撕裂迷雾的尖啸——本该是终结。

但史莱姆凝胶状的躯壳却只凹陷下去，发出低沉的嗡鸣。烟雨的身影掠过，长刀在月光下划出一道银色弧线。银弧一闪而逝，如流星坠入泥沼。怪物溶解，只余一地微光粘液，蒸腾着刺鼻的酸腐气。

「啧。」
她收刀归鞘，靠上旁边一块覆满青苔的岩石，黑发如瀑垂下。

「月光让它们变难缠了。」骸云鼻尖翕动，仔细分辨着空气中残留的异样。他俯身掏出小瓶，爪尖谨慎地剐蹭那滩粘稠物质。
「这玩意...卖给炼金术士的话，」瓶口在月光下折射出贪婪的光，「能比普通凝胶贵几倍？」

「又闻到金币味了？」烟雨目光落在他专注的脊背上。

她的记忆里除了骸云，一向独来独往，自给自足惯了，金币对她并非必须。她也懂交易，懂情报的价值。只是...狼兽人？做生意？她实在想象不出这只灰狼龇着牙跟人讨价还价的样子——不会把客人吓跑吗？

视线随意勾勒着眼前的灰狼：稍比她高壮的北方兽人，据他说，自己立志成为吟游诗人而离群索居。在族群里或许还是只幼崽，此刻那身灰白皮毛在月下泛着银光，尾巴尖正因专注而微微摇晃。

呵，不过是一只...会自己梳毛的大狗罢了。
难道说，**狼**不可貌相，那——试试这样呢？

一抹促狭的笑意爬上烟雨嘴角。她悄无声息地潜近，靴底碾碎腐叶的微响被雾吞没。手指精准地攫住那蓬松晃动的尾尖，然后猛地一拽！

「嗷——！」

骸云惊跳而起，瓶子脱手滚落。恶作剧得逞的少女肩膀轻颤，憋着笑：
「知道吗？你这尾巴，」她指尖捻了捻柔软的毛发，「手感绝佳。」

低沉的咆哮在狼的胸腔震荡：「放开！全糟蹋了！」灰狼扭身挣扎。

「这可是你说的噢~」
毫无预兆地松手。重心顿失的狼狼狈扑地，激起一片湿叶和泥点。

「啧啧，真够'狼'狈的。」烟雨踱步上前，靴尖轻点他拱起的后腰。

不满的呜咽闷在泥土里。重获自由的灰影骤然暴起，带着草屑和怒气，一个猝不及防的猛扑！

少女纤细的身形被轻易压倒，陷进湿冷的落叶与草中。她却浑不在意，双手精准地捧住那张毛茸茸的脸，狠命揉搓。粗糙皮毛下是温热的兽息，金黄瞳孔里燃烧着被戏弄的恼火。

危险仍在雾中潜行，而两人滚作一团。

# 祭坛

越往迷雾深处行进，空气就越像水一样凝滞。烟雨和云没有交谈，只用眼神确认方向。林间鸟兽皆寂，只剩下脚步碾压落叶的碎响。

终于抵达了古卷上标示的地点——一块由十三根石碑围成的空地，被遗忘于时间深处的仪式场。  
中央的石台上，宝石悬浮着，散发着蓝白交织的光。魔力的波动扭曲了周围的空气，仿佛整片森林都在屏息。

「 找到了，只现身于满月的宝石！ 」云低声说，声音里夹杂着几分压抑不住的兴奋。他舔了舔嘴唇，朝宝石迈出一步。

「 小心, 没那么简单! 」她盯着前方，眼神像刀一样扫过空地。

雾在动，不自然地动。就像有什么东西藏在里头，正在缓缓游走。

下一瞬，幽灵狼从雾中跃出。

它像是一团雾构成的野兽，身形虚实交错，眼中燃烧着蓝色的火焰，身体近乎透明，却压出实质的杀气。

烟雨瞬间出刀，横斩而出，月光反射在刀刃上，像一道闪电。

刀锋穿过了狼的身体，却几乎没有阻力。

“砍到了……？”她皱眉，却没听到血肉破裂的声音。

“没用。”云低声咒骂，已经拉开长弓，一箭射去。

箭矢贯穿了幽灵狼的胸口——它却连半点反应都没有。

“这东西不是完整的。”烟雨沉声说。

“是幻影。”云说，“也许……也不全是。”

幽灵狼再次发动攻击。这一次，它的利爪几乎贴着地面掠来，动作异常迅速。烟雨后跳避开，却感到空气像是被利爪切开，带着割裂的风压。

她落地半蹲，长刀支地，冷汗沿着脸颊滑落。

云立刻换了手势，吹起那支木笛。笛音清透刺耳，直冲雾气。  
淡蓝色的光从笛口溢出，化作细线缠绕在烟雨的刀身上，像是唤醒了某种沉睡的力量。

“试试看。”他简短地说。

烟雨起身，没有回话，只是再度踏步上前。  
她的动作更轻、更快，刀锋横切，划向幽灵狼的腹部。

这一次，刀身与虚影相触的一刻，爆出一道蓝色火星。

幽灵狼发出一声低沉的咆哮，身形一颤，终于第一次显露出了**被击中的反应**。

“有效。”烟雨低声确认，脚下没有停，接连几刀压上去。

幽灵狼被迫后撤，爪刃与刀光交错，不断迸出短促的火花。它在防御，也在找机会退走。

突然，它仰头发出一声长嚎，声音穿透雾气，在林间激起回响。

“糟了，它在呼叫同类！”云脸色一变，“不能让它成功——！”

烟雨没有犹豫，直接冲刺上前，刀光如月弯。

最后一斩划下，幽灵狼的咽喉被撕裂成一缕缕雾气，它像被扯碎的布匹一样从中间崩解，连嚎叫也断成了无声的残响。

雾仍未散，但空地归于死寂。

烟雨收刀，站在原地喘息。云落地站定，瞄了几秒后才放下弓弦。

“结束了？”云问。

“不知道。”烟雨抬起头，眼中仍有寒光，“但下一场，应该快了。”
