# 序

面试结束的时候才四点多，十一月的空气不冷不热，说不上秋高气爽，但让人舒服。我从楼下扫了一辆共享单车，刚踩上去整个人就松下来——原来我并没有自己想得那样“不够格”。

本来以为答得很一般的笔试，说不定连面试的资格都保不住。那会儿心里只是想着：“既然来了，就留下来看看自己到底差在哪。”
结果没想到，等来的却是那句随口却救命一样的话：“你们三个答得还算可以。”

一整张会议桌的人被一个个筛掉，最后就剩下我们三个。我骑着车往回走，路不远，风也不大，但我心里反而有点轻快。
面试官讲的方向和培养机制，是我从大学到现在想过无数次、却一直没真正摸到过的东西。那种感觉像是：原来自己并不是彻底站在门外。

真正扎进心里的，是他语气很平常的一句话：

> “我们要求工程师掌握一门编译型语言和一门脚本语言。”

我当时只是点了点头，没多说。但那句话像是贴在耳边的东西一样，被我一路带回了家。甚至等我打开门、把钥匙放下，它还在脑子里慢慢重复。

不是因为这句话有多难，而是我第一次很明确地意识到：
这个行业里存在的东西、却没人系统告诉过我的那条“能力路线”。像是有人在不经意间，把一盏小小的灯举到我面前，照到了我一直摸黑走的地方。

# 摸着走

回想大学这三年将近四年了，学校安排的东西不少，什么都让我碰一点。
C 语言、前端基础、后端框架、Python、计算机硬件、嵌入式……课横着铺一整排，但安排到的学习时间，一周就一两次课，还有陈年老窖的 PPT。
只能课后全靠自己摸，学得多，难免浅。

那时候我也怀疑过自己。是不是方向太散？是不是这样反而哪里都抓不稳？

可后来才慢慢发现，不只是我，大家其实都是这样的。乱学至少说明我在动，没摆烂。
当时学 Vue 搭网站那阵，虽然没人教、全靠自己试，也是真的花了不少时间，但我现在回头看，那股劲儿挺难得的。

大学的路数本来就是这样——先让你接触，再让你自己找路。只是有人早早定了目标，而我属于那种：
边试边走，不算快，但也确实一步步往前挪。

最终选 Java，因为它就是我当时能看到的、最稳的入口——

> 能把我带进互联网这个更大的世界。

虽然网上的负面消息看多了确实让人焦虑，但至少这次面试让我重新把那股信心捡了回来。所以当面试官提到“编译型 + 脚本型”的组合时，我心里那一下不是惊讶，而是那种：

**“原来我没跑偏。”**

甚至有点意外——我之前从没往这方面想过。就像在杂乱的路线里跑了很久，突然踩到了一个方向感很强的点。

# Go

回到出租屋，本来想着先躺一会儿，可回来的那段路上反复绕着的那句话一直没散开，让我越躺越不安稳。最后还是坐到桌前，把电脑打开，想着至少弄明白 Go 到底是在干什么。

最开始我看的都是最基础的东西：
是谁做的、现在主要用在哪、为什么这么多公司在谈它。原本以为会很枯燥，结果越翻越觉得——它不像我之前想的那么小众。

我以前只是隐约听过“云原生、微服务那些团队在用 Go”，但那天认真查了一圈才发现，不少做底层服务、工具链、甚至一些 AI 小工具的项目，都在靠它撑着。那种“不是用来秀技术，而是确实在扛活”的感觉，很容易看出来。

有两个点让我印象比较深。

**一个是并发。**
第一次看到 goroutine 的例子时我愣了好几秒——
Java 的线程那一套我多少有点了解，复杂、啰嗦、要处理的东西多。但 Go 里那种“随手就开一个”的写法，让我一下意识到：
原来并发也可以这么轻、这么直接。

**另一个是部署。**
我看到有人说：“Go 打包就是一个文件，丢到服务器就能跑。”
那一瞬间我脑子里冒出的就是一句：
“这也太直接了吧？”
和 Java 工程那整套目录结构、依赖体系比起来，这种差异是能立刻感受到的。

语法我也看了一点，最直观的感受就是干净。没有那么多层层叠叠的框架，很多东西就是一个函数，一行代码说清楚。

总的来说，还是很浅的东西。就是一个普通实习生第一晚能触到的程度，连入门都算不上。
但就这点浅浅的了解，也让我第一次意识到——

> Java 做业务，Go 做底层，Python 做工具

这三门语言凑在一起，并不是潮流，而是一种很自然的分工。原来“编译型 + 脚本型”不是一句要求，而是一种行业里真实存在的工程组合。
如果未来真想成为一个更完整的工程师，我可能真的不止是写 Java，而是要慢慢补上这套组合的底子。

# 方向在风里

关上电脑的那一刻，我才意识到，重点根本不在 Go 本身，也不在我那天晚上到底吸收了多少。真正让我停下来的，是一种久违的清醒——我第一次不是从“还能学点什么”的角度看自己，而是从“工程师是怎样长起来的”这个方向重新想了一遍。

原来前台有 Java 负责业务，下面是更偏工程的 Go，再旁边有 Python 在做脚本和小工具。以前我从没把这些内容串成一条线，总觉得自己学得杂，却哪里都抓不稳。但那天晚上我突然明白，能力其实可以一点点往上叠，不必靠一门语言硬撑到底。

让我意外的是，我居然不排斥这一切。
不抗拒新东西，不害怕跨栈，只要能看懂一点，我就愿意往前再迈半步。
这种愿意，是这几年里少见的，也让我重新找回一点踏实感——那种“好像真的能往前走了”的感觉。

窗外的风还是乱的，十一月的夜吹得不急不慢。世界也不会因为我多看了几篇资料就变得温柔。但不知为什么，我心里那团浮着的东西落了下去。

以前我总觉得自己是在被风推着走，走到哪算哪。但那天晚上，我第一次觉得：

> **在这些凌乱的风里，我有了一个可以靠近的方向。**

Go 于我不是立刻要掌握的技能，而是一个象征——
它提醒我，未来不是靠一门语言吃饭，而是靠我愿不愿意一点点叼住新东西，把它们磨成自己的牙齿。

我现在当然还不熟练，甚至连入门都算不上。但那一点点愿意向前迈步的劲，比会不会语法更重要。

风依旧紧。
可这一次，我愿意压低身子，顺着那条终于能看清一些的路，稳稳地往前跑下去。
