# 序

面试结束的时候才四点多，十一月的风也不冷不热。说不上秋高气爽，但让人舒服。我从楼下扫了一辆共享单车，刚踩上去，整个人就松下来——原来我并没有自己想得那样“不够格”。

本以为答得很一般的笔试，甚至做好了连进面试都不配的心理准备。那会儿心里只是想着：“既然来了，就留下来看看自己到底差在哪。”
结果没想到，等来的却是那句平和却救命一样的话：**“你们三个答得还算可以。”**

一整张会议桌的人被一个个筛掉，最后就留下我们三个。我骑着车往回走，路不远，风也不大，但我心里反而有点轻快。
在通过了笔试后，面试官向我们介绍公司的方向、培养机制。那些我大学这三四年想过无数次却从没机会真正接触过的东西，在那一刻忽然变得能够触到、甚至能靠近。

令我印象深刻的，是他语气平平的一句话：

> “我们要求工程师掌握一门编译型语言和一门脚本语言。”

我当时只是点了点头，没多说。但那句话像是贴在耳边的东西，被我一路带回了家。甚至等我打开门、把钥匙放下，它还在脑子里慢慢重复。

这让我第一次意识到：
这个行业里存在的东西、却没人系统告诉过我的那条“能力路线”。像是有人在不经意间，把一盏小小的灯举到我面前，照到了我一直摸黑走的地方。

# 摸着走

回想大学这三年将近四年了，学校安排的东西不少，什么都让我碰一点。
C 语言、前端基础、后端框架、Python、计算机硬件、嵌入式……课横着铺一整排，但安排到的学习时间，一周就一两次课，还有陈年老窖的 PPT。
只能课后全靠自己摸，学得多，难免浅。

那阵子我常怀疑自己——是不是方向太散？是不是每样都只够够不着？是不是这样的人，最后哪儿都站不住？

可后来才慢慢意识到，不只是我，是环境让所有人都在这样乱撞。当时学 Vue 搭网站那阵，虽然没人教、全靠自己试，也是真的花了不少时间，但我现在回头看，那股劲儿挺难得的。

大学本来就不是帮你修好一条路，它只是把入口甩给你，然后你自己去趟。只是有人早早定了目标，而我属于那种：
边试边走，不算快，但也确实一步步往前挪。

最终选 Java，因为它就是我当时能看到的、最稳的入口——

> 能把我带进互联网这个更大的世界。

网上的风声负面不少，看得久了难免焦虑。但至少这次面试让我重新把那股信心捡了回来。所以当面试官提到“编译型 + 脚本型”的组合时，我心里那一下确定了：

**“原来我没跑偏。”**

甚至有点意外——我之前从没往这方面想过。就像在杂乱的路线里跑了很久，突然踩到了一个方向感很强的点。

# Go

回到家，我还在想着面试里遇到的那些事。

我现在正在尝试的这一套大多围着 Java 打转，可外面的工程世界貌似并不只是一门语言。我突然有点想看看，那些面试里频繁被提到的技术，究竟长什么样。把电脑打开，想着至少弄明白 Go 到底是在干什么。

一开始只是查最基础的：是谁做的、为什么火、主要在哪些场景用。
本来以为只是随便翻翻，结果越看越觉得——它并不小众，反而是很多底层服务、工具链、甚至一些 AI 小工具背后的“扛活语言”。不是炫技，而是确确实实在干工程活的那种。

我以前只是隐约听过“云原生、微服务那些团队在用 Go”，但那天认真查了一圈才发现，不少做底层服务、工具链、甚至一些 AI 小工具的项目，都在靠它撑着。那种“不是用来秀技术，而是确实在扛活”的感觉，很容易看出来。
两个地方让我一下子记住了。

一个是并发。
第一次看到 goroutine 的例子，我愣了好几秒。Java 的线程模型我略懂一点——结构复杂、要处理的东西多。而 Go 的写法轻得离谱，像是在告诉你：并发不是高墙，而是能直接迈过去的门槛。

另一个是部署。
看到“打包就是一个文件，丢到服务器就能跑”的时候，我心里只有一句：也太干脆了吧。和 Java 那套工程体量相比，这种干净俐落的差异立刻能感受到。

语法我也瞄了一点，整体就是“干净”和“直接”。不用框架叠框架，很多东西就是一个函数，一行讲清。

当然，这些只是第一晚能触到的最浅层的理解，连入门都算不上。但就是这些，让我第一次把几门常见语言连成了一个清晰的工程图谱：

> Java 做业务，Go 做底层，Python 做工具

这并不是潮流，而是工程师在真实世界里协作的自然分工。“编译型 + 脚本型”的要求也不再像一句面试官随口提的要求，而是一个能力体系的轮廓。

我第一次意识到，未来如果想往前走，我大概不会只停在 Java 上。我得慢慢把这一整套底子补起来。

# 方向在风里

关上电脑的那一刻，我才意识到，重点根本不在 Go 本身，也不在我那天晚上到底吸收了多少。
正让我愣住的，是一种久违的清醒——我第一次不是从“还能补点什么”的角度看自己，而是从“工程师究竟是怎样长起来的”这个方向，把整个路径重新想了一遍。

原来前台有 Java 负责业务，下面是更偏工程的 Go，再旁边有 Python 在做脚本和小工具。以前我从没把这些内容串成一条线，总觉得自己学得杂，却哪里都抓不稳。但那天晚上我突然明白，能力其实可以一点点往上叠，不必靠一门语言硬撑到底。

让我意外的是，我居然不排斥这一切。
不抗拒新东西，不害怕跨栈，只要能看懂一点，我就愿意往前再迈半步。这种愿意，也让我重新找回一点踏实感——那种“好像真的能往前走了”的感觉。

窗外，十一月的夜吹得不急不慢。世界也不会因为我多看了几篇资料就变得温柔。但我心里那团浮着的东西落了下去。

以前我总觉得自己是在被风推着走，走到哪算哪。但那天晚上，我第一次觉得：

> **在这些凌乱的风里，我有了一个可以靠近的方向。**

Go 于我不是立刻要掌握的技能，而是一个象征——它提醒我，未来不是靠一门语言吃饭，而是靠我愿不愿意一点点叼住新东西，把它们磨成自己的牙齿。

我现在当然还不熟练，甚至连入门都算不上。但那一点点愿意向前迈步的劲，比会不会语法更重要。

风依旧紧。
可这一次，我愿意压低身子，顺着那条终于能看清一些的路，稳稳地往前跑下去。
