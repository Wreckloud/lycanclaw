最近因为一个人，心绪翻涌了许多。
这一刻，这种前所未有的感觉，太珍贵了，不容被时间冲淡，我要在此为它留一个位置。

# 一个人也挺好

我一直以为，一个人也挺好的。  
有自己的兴趣，有几来位挚友，偶尔热情，足矣。  
大多数时间里，我都活在自己的小世界里，做着自己喜欢的事情、想象着脑海中的一片净土，那里有一位不属于现实的陪伴者——  
那是一只狼，也可能只是个模糊的影子。  
它是我幻想里能让我安心的存在，能陪我坐在心里最深的那个角落，不说话，但始终在场。

我以为这就足够了。  
直到他出现，把我用来安慰自己的“足够了”一下子击碎了。

# 光的出现

他的靠近，不是轰然降临，而是一点点的，就像冉冉升起的太阳逐渐照亮阴沉的大地般。  
我关注他，起初是因为画的狼。后来加了他的群，是因为他本身就是一个愿意分享、帮助他人的人，我恰好也想要提升自己。  
接着，我心中难免会有些崇拜，写了一篇关于他的文章，挂在自己博客中，以为没人会看到。结果却被他看到了——不仅仔细读了，还主动来和我打招呼。

那一刻，我爆炸了。  
我以为我写的那些话只是对着风说的，没想到，竟真的被听见了。  
他回应得自然，我们开始聊天，开始分享喜欢的东西，我惊奇地发现，我们有许多共同爱好。

# 应付不来的担忧

我越来越靠近，也越来越快乐，但我也越来越害怕...
怕说错话，怕他有一天突然就不再回应了，最怕失去这一切的美好。  
我小心翼翼，每一句话都在心里过一遍；我明明很想找他说话，却又担心自己是不是太过贪心，太打扰了他。

我开始怀疑，怕只是我太久没体会过这种善意， 错把善意当作热情；怕他只是我幻想中的那只狼的投影，是不是只有我一个人在认真期待。
他表达时的自然与真诚，他懂得比我多却不自傲的样子，他乐于分享时的眼神和语气。他是那个把我幻想都收回去的人，他给了我最渴望的回应。

我们从晚上聊到凌晨，话题在半夜慢慢停下来了，但我却怎么都睡不着。  
我的心仿佛已经不安于独处了。

这种感觉在我前几十年从未有过：  
或许那种和另一个人并肩走下去的生活，真的存在；  
或许，我也有可能成为那样关系的一部分。

理智告诉我，一切未必会走到我所期望的终点；  
但本能却一次又一次抬起头、追问我自己：  
“如果真的能靠近，就靠近吧……哪怕只有一次，也值得试试看。”

# 我不想再一个人了

一直在幻想之地寻求一丝慰藉的我，怎么能承受得住这种情感。  
所以我把这一切都记录下来。

哪怕这段关系不会像童话故事那样完满；  
哪怕未来我们各自有路，各自的生活终将远离屏幕；  
哪怕现实里还有很多不确定……

但！！我也仍然愿意靠近，我要为此做出改变，让我值得被靠近。  
这是我活这么久，第一次，发自内心地说：

> **我不想再一个人了。**

我想让自己变得更好，我要成为一个值得被回应、值得被信任的人。

从习惯独行，到学会靠近；  
从觉得一个人也行，到发现——  
**我想要同行，也会值得同行。**

这篇文章，可不能像之前那样，“轻易” 地被现在的你发现哟~
