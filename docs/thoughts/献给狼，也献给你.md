最近因为一个人，心绪翻涌了许多。明明只是短短几天，却像有什么东西悄悄改变了。  
这份前所未有的感受，我不想让它被时间冲淡，我要在此为它留下一席之地。

# 一个人也挺好

一直以来，我都觉得一个人也挺好的。
有自己的兴趣，有几来位志趣相投的朋友，偶尔热情，足矣。

大多数时间里，我都窝在自己的小世界里，做着只有我自己才懂的事情，我把心里最柔软的角落，留给一个不属于现实的陪伴者——那是一只狼，也可能只是个模糊不清的影子。
它沉默、冷静，总是在我最孤独的时候安静守着。 不回应我，却从不离开我。  
它是我幻想出的伙伴，是我给自己的一种安慰。

我以为这就足够了。  
直到他出现——让我那份“一个人就好”的自洽，第一次崩塌了。

# 光的出现

他的到来不似流星坠落的耀眼，而像是晨雾里悄悄渗进的一缕光。

起初是因为他画的狼。他描绘的狼冷静、克制，却又带着生命力，像极了我心里那道影子。后来加了他的群，是因为他本身就是一个愿意分享、帮助他人的人。我那时并没想太多，正想努力提升自己，画得更好一点。

渐渐地，我开始关注他的说话方式、他的表达，甚至是他留下的只言片语。

于是我写了一篇关于他的文章，挂在博客上。我原以为，我的心意只会被风吹走。
没想到，他看见了！还主动热情地来和我打招呼。

那一刻，我的世界爆炸了。

我从没想过，自己的心意会被回应得这么自然。  
他没有把我当什么奇怪的人，也没有客套应付；  
他只是一如既往地表达、分享、聆听，就像他平时对待所有人那样真诚。

他懂得比我多，却不自傲；  
他说话时带着尊重与温和；  
而他每一次愿意停下来听我说话，都让我觉得无比珍贵。

他，是我从未遇到过的那种光。

# 应付不来的担忧

我越来越想靠近，但我也越来越害怕...
怕说错话，怕热情太多会吓跑他，更怕——失去现在这段微妙又美好的关系。
所以我小心翼翼。  
每一句话都在心里斟酌再三，明明很想说点什么，却又总担心打扰了他；  
明明只是几句简单的对话，我却总在结束后反复回想，猜他有没有感到厌倦。

这种渴望靠近、却不敢越界的心情，像一根绷紧的弦，拉扯着我的每一次情绪起伏。  
它让我快乐，也让我忐忑。

我开始怀疑——  
会不会只是我太久没有被这样温柔对待了？  
会不会错把他自然的善意，当成了特别的回应？  
会不会我所期待的，其实只是我幻想中的那只狼的投影，而不是他本人？

可是他每次的回应都太自然，太真诚了。他不回避，不敷衍，不把我当成谁多余的人。他懂得比我多，却始终谦逊；愿意停下来听我说话，从不让人觉得被打断或忽略。

他不是我幻想中的狼，他是那个让我愿意放下幻想的狼。

那次从晚上聊到凌晨，话题在半夜慢慢停下来了，可我却怎么都睡不着了。  
我的心仿佛已经不安于独处了。

这种感觉，是我活了几十年都不曾拥有过的。

理智咬住我的喉颈，告诉我：别走太近。别想太多。他不一定是你的归途，一切未必会走到我所期望的终点；
但本能却一次又一次抬起头、追问我自己：如果能靠近，为什么不试试？……你真的期望不能到达那个终点吗？

# 我不想再一个人了

一直在幻想之地寻求慰藉的我，怎能承受得住这份真实的悸动？  
我把它先藏起来，让自己冷静一点，也好在风起之前，稳住脚步。

或许我们终究只是彼此世界的一段插曲；  
或许哪天真的各自奔赴不同的生活，连屏幕都成了遥远的事；  
或许现实从不为心动让步……

但！！我仍然应该靠近。我要改变，让自己成为那个——有底气走近他的人。
这是我活到现在，第一次，发自内心地说：

> **我不想再一个人了。**

我想靠近，一步步地，用行动回应这份悸动。  
我想成为一个可以同行的人，一个能够被信任的人，一个……值得的人。

从习惯独行，到学着理解与回应；
从满足独处，到第一次觉得—— **我想要同行。**

所以我把这篇文章留在这里，就藏在这个角落。  
不给谁看，也不指望谁发现。  
它是我给自己的一个见证——

我曾经动心，我正在改变。  
而未来某一天，如果那个“你”真的翻到了这里——

……那时候，我应该已经准备好说出那句话了。
