# 晨

今日破晓时分的寂静难得令人愉悦，我舒展着肩颈推开卧室门——

直到餐桌上的"礼物"刺入眼帘。

# 骨与花

我凝视着那截斜插的腿骨，晨光正沿着它爬行，勾勒出干涸的暗红色纹路。这匹狼甚至贴心地绑着束野蔷薇——用他昨晚捕猎时撕裂的亚麻衬衫扎成蝴蝶结。花瓣上凝着露珠，缓缓沿着花茎滑落。

我用指尖捏着骨头，已经数不清收到骸云"礼物"的次数。从沼泽巨蜥的毒牙到嵌着碎晶的岩龟壳，现在他居然学会给战利品做造型了。
那支野蔷薇的根部还粘着可疑的暗红碎肉，让整个房间弥漫着淡淡的铁锈与腐甜。
而始作俑者正蜷在壁炉旁，蓬松的灰色尾巴正盖着鼻尖随呼吸起伏。

我揪住他后颈的刹那，那对毛茸茸的耳朵立即从戒备状态耷拉成软绵绵的投降姿势。

「早安气味。」
他喉间滚出低沉的咕噜，一副没完全清醒的样子说道：
「木屑、铁锈和...愤怒的蔷薇花？」

「说过多少次——」
「没有人类会喜欢骨头器官当装饰品，上个月你送给隔壁领主的礼物...」
我掰着他的下巴，好让这匹笨狼能够清醒些。
「是血淋淋的魔熊心脏？」

「是最珍贵的部位，嗷。」
「你们人类不是用红色表达爱意吗？」
骸云挣扎着歪头，他全然不知那张通缉令正贴在隔壁城镇的公会告示栏——那潦草的炭笔把他画得像头直立的山猪。

为了让这只狼能够意识到自己的问题，我抄起“礼物”，指节缓缓收紧在那截腿骨上。

灰狼似乎意识到了危险，本能地弓背后缩。
「这...这.可是爪刃兽的腿骨！」
他喉咙里挤出示弱的呜咽，
「能当磨牙棒，或者...」

我没理他，只用骨头的另一端落在他额头上，声响倒挺唬人——像敲在砧板上。
他倒好，立刻哀嚎着缩成一团，捂着脑袋一头栽到壁炉边，动作比上次被石化蜥蜴撞飞还浮夸。

「装疼倒是越来越熟练了。」
我大步靠近，一手揪住他耳朵，一手将腿骨放在指间不紧不慢地旋着。
「上次被石化蜥蜴撞飞都没见你哼一声的。」

看来刚刚那一下并没能让他认识到错误，我将骨头猛地一收，精准戳向他腰侧那块软肋，我当然知道这才是他真正的弱点。然后，正如预期的那样，这匹狼的胸腔里爆出一声夸张的呜咽，壁炉上的灰扑簌簌地往下落。

腿骨在指间一停，收回手时我的嘴角抬了一点弧度。
「下次记得，别想靠卖乖蒙混过关。」
...

# 沉于皮毛

骸云被突如其来的责难击败，委屈地趴在一旁，一爪护着腰侧不肯动，像是受了天大的冤枉。

我自顾自抽出小刀，贴着骨头慢慢剔去残痕。刀刃处的狼牙打磨得锋利，刀柄光滑温润，正好贴合掌心。这把犬齿小刀是他乳牙期脱落的犬齿打磨而成的礼物——当时这只笨蛋满面血痕地出现，慌张地以为自己要死于换牙了。

啧。

想到这，我心里那点没好气忽然就泄了个干净，嘴角不自觉扬了起来。
「哼，下次直接送花吧。」
我扯了扯他软垂下去的尾巴尖，把清理干净的腿骨放到一旁，语气缓了下来：
「人类更喜欢不会蠕动的东西。」

骸云耳朵倏地竖起，尾巴也跟着扫了两下地板，像是嗅到了转机——
「好！」
下一秒，他整匹狼窜了起来，把我整个压倒在地板上。我还没骂出声，可一回神，整颗狼头已经拱进我颈窝，鼻吸炽热得像贴了团小火。

「鼻子，离我远点！」
我用手肘顶住他毛茸茸的胸口，嘴上嫌弃，动作却没用全力。他得了便宜，蹭得更来劲了，尾巴用力敲在壁炉边。

晨光落在他耳尖，交缠的影子贴在壁炉砖上。那支野蔷薇还躺在桌边，花瓣沾着齿痕，比任何魔法造物都鲜活。
